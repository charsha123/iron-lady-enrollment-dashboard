 📌 Project Overview
This project is a **web-based internal dashboard** designed to automate and streamline **Iron Lady’s internal enrollment management process**.

The application replaces manual processes (spreadsheets, emails, follow-ups) with a **single centralized system** that allows internal teams to efficiently manage enrollments across multiple programs.

Built using **Python and Streamlit**, the solution focuses on **business relevance, usability, and operational efficiency**.

---
 🎯 Problem Statement
Iron Lady runs multiple programs such as:
- Skill Development Program
- Leadership Program
- Career Readiness Program

Managing enrollments manually can lead to:
- Data inconsistency
- Delayed updates
- Human errors
- Increased administrative workload

---
 ✅ Solution
The **Internal Enrollment Management System** provides:
- A centralized enrollment dashboard
- Real-time updates
- Automated CRUD operations
- Simple and intuitive interface for internal teams

This significantly reduces manual effort and improves efficiency.

---
🔄 Workflow Explanation
1. Admin adds a new enrollment (Name, Email, Program, Status)
2. Enrollment is instantly stored and displayed in the dashboard
3. Admin can update enrollment status (Pending / Approved / Rejected)
4. Admin can delete enrollments when required
5. The dashboard updates automatically without page reloads

---
 🧩 Features
- 📝 Add new program enrollments  
- 📊 View all enrollments in a structured table  
- 🔄 Update enrollment status  
- 🗑️ Delete enrollments  
- 💾 Session-based data storage (no external database required)  
- 🎨 Custom polished UI (not default Streamlit styling)

---
🛠️ Technology Stack
- **Python**
- **Streamlit**
- **Pandas**
- **HTML & CSS (custom styling)**

---
🧪 CRUD Flow Implementation
| Operation | Description |
|---------|------------|
| Create | Add a new enrollment |

This satisfies the requirement of **at least one complete CRUD flow**.
